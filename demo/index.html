          Why this is not just an API call
          
        
          
          
          
            
          The model is one stage of eight
          
            
          
              Dates, deadlines, participants, unanswered questions and how long a
              thread has waited are all found by ordinary code, then handed to the
              model as ground truth and shown to you directly. A deadline
              on screen is one a program found in the text.
            
          
          
          
          
          
            
          Nothing it says is taken on trust
          
            
          
              Every date, amount and address in the summary is checked against the
              source. Anything that cannot be traced back is shown as unverified,
              with the specifics.
            
          
          
          
          
          
            
          Attacks are detected and defused
          
            
          
              When an email tries to instruct the assistant, you are told, the
              model is warned before it reads, and the recommended action is
              replaced deterministically — because during evaluation the
              model described an attack correctly and then advised complying
              with it.
            
          
          
          
          
          
            
          Attachments are guilty until proven innocent
          
            
          
              File types come from content, never a filename. Macros, zip bombs
              and traversal entries are refused, and the readers that do run live
              in a separate process with capped CPU, capped memory and no ability
              to write to disk.
            
          
          
          
        
          
      
          

      
          
        
          Measured, not asserted
          
        
          
          
          15/15golden dataset cases, reproduced on two runs
          
          
          390tests, 97% line coverage
          
          
          ~18sper thread on an 8 GB M1, fully offline
          
          
          7 → 15eval score before and after the fixes it prompted
          
        
          
        
          
          Fifteen cases is a small dataset written by one person, so it measures
          the failures that were anticipated, not general accuracy. It earns its
          keep by catching regressions and by having found real bugs.
