    EmailAssist analyses your mail with a language model running on your machine — a static site has nowhere to run one, so the button below is real but disabled. Every result in History is genuine output from the real pipeline, captured by running it locally against the project's own test threads — the script that captured it is in the repository, and so is the raw data. Clone the repo and run make setup && make model && make run to try it on your own threads.
